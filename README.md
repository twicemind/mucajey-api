# Mucajey API

Node.js/Express backend that powers the Mucajey apps. It exposes registration and authentication, API-key protected card/edition/stat endpoints, and supporting middleware for caching and Passport strategies.

## Features

- Express 5 server with Passport local (session) and header API-key strategies
- Routes
  - `GET /health` – health probe (no auth)
  - `POST /registration` – create/update API key metadata (no auth)
  - `POST /auth/login`, `POST /auth/logout` – session auth with Passport local
  - `GET /auth/me` – current user info (session)
  - `GET/POST/POST /password/DELETE /auth/users` – admin-only user management
  - `GET/POST/PATCH/DELETE /card` – API-key auth via `passport-headerapikey`
  - `GET/POST/PUT/DELETE /edition` – API-key auth via `passport-headerapikey`
  - `GET /stats` – aggregates cards/editions (API-key auth)
- Mongo-backed caches for cards, editions, services, and users
- OpenAPI generation (`scripts/openapi`) with YAML output
- Jest test suite with coverage reporting and docs export (`docs/test/latest.md` and `docs/lint/latest.md`)
- Docker image publishing via GitHub Actions (tags: package version + `latest`)

## Getting Started

1. Install Node.js (>=18) and MongoDB.
2. Copy environment template: `cp .env.example .env` and adjust Mongo URIs, session secret, master API key, etc.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the API:
   ```bash
   npm start
   # or development reload
   npm run dev
   ```

## Testing & Linting

- Run full CI bundle (lint + Jest + audit):
  ```bash
  npm test
  ```
- Just tests with coverage:
  ```bash
  npm run test:jest -- --coverage
  ```
  Coverage artifacts are written to `coverage/` (lcov) and summarized in `docs/test/latest.md`.
- Lint (ESLint v9 flat config):
  ```bash
  npm run lint
  ```
  Latest lint report is stored in `docs/lint/latest.md`.

## OpenAPI

Generate route-derived OpenAPI and bundled output:

```bash
npm run openapi:build
# generates scripts/.cache/openapi.json and openapi.bundle.yaml
```

## SBOM

Create a CycloneDX SBOM with npm:

```bash
npm run sbom
# writes sbom.json (serialNumber generated by npm)
```

## Docker

- Local build:
  ```bash
  docker build -t mucajey-api:local .
  ```
- CI publishes two tags: `${package.json version}` and `latest`.

## Project Layout

- `src/server/server.js` – Express setup, Passport strategies, route wiring
- `src/server/routes/` – route handlers (v2 routes use local or API-key auth)
- `src/server/middleware/` – Passport strategies, Mongo caches, Mucajey auth helpers
- `src/test/` – Jest test suites (routes, middleware, utils)
- `scripts/openapi/` – OpenAPI generation/bundling
- `docs/` – latest lint/test reports and coverage summary

## Notes

- Passport local strategy expects users stored via `/auth/users` endpoints; API-key strategy checks the service cache.
- Make sure Mongo contains seed data for cards/editions when exercising card/stat endpoints.
